**Next print: Rev G.** The maximum drawing and alternate supplier pack now clear the case and insert from above. Print the housing, west-side key retainer and wire bridge. Use the [Rev G print kit](https://github.com/natthapolvanasrivilai/thai-waters-handheld/releases/download/rev-g-fit-print/Riffle-Rev-G-fit-print.zip), [fit procedure](hardware/mechanical/rev-G/README.md) and [interactive 3D viewer](docs/models/Riffle-Rev-G-exploded.html) for this build.

Personal product project of GitHub user natthapolvanasrivilai. Rev G carries forward the Rev F top-left power key and screw-locked rod grip. It uses the Waveshare capacitive touchscreen controller module. Production disposition is HOLD for physical verification, supplier documentation and market classification.
