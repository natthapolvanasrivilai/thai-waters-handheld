**Next inert print · TW-A-0001-R0008.** Use all twelve supplied device orientations and both inert gauges. The A1 PETG slice uses support only on the housing and rotor and reduces total support from 13.95 g to 4.82 g. First-article fit and strength remain open. [Download the print kit](https://github.com/natthapolvanasrivilai/thai-waters-handheld/releases/download/TW-A-0001-R0008/TW-A-0001-R0008-fit-print.zip) · [Print setup and fit procedure](hardware/mechanical/TW-A-0001-R0008/PRINT-GUIDE.md) · [Exploded viewer](docs/models/TW-A-0001-R0008-exploded.html)

Personal product project of GitHub user natthapolvanasrivilai. The R0008 build retains the top-left power key and screw-locked rod grip. It uses the Waveshare capacitive touchscreen controller module. Production disposition is HOLD for physical verification, supplier documentation and market classification.
