# Simulator source
Open Thai-Waters-play.html directly for offline desktop play. For phone motion and shared events use lan/README.md. Toggle Screen only for an unobstructed gameplay view. On the modeled LCD, tap to cast or lift and tap MENU to navigate. Grab the right-side reel and move the pointer around its projected axle. Fold reel pivots the amber grip into the modeled well. The near-edge green shell, bezel, rotor, grip, collar and retainers come from Rev E geometry. Surface finishes are a visualization.

Run python game/build.py from the repository root to regenerate the self-contained viewer from local assets. It has no CDN dependencies. To rebuild the renderer, enter game/src, run npm ci, then npx esbuild play-device.js --bundle --minify --format=iife --outfile=../assets/device-renderer.min.js. The WebAssembly is compiled from firmware/tests/bench.cpp with Zig C++ targeting wasm32-wasi and linked with wasm-ld --no-entry --export-dynamic --allow-undefined --strip-all. Use the functions imported by the packaged viewer. The firmware and browser share the game, pose, wheel and audio code.

Game data lives under content and locations.json. Stable IDs preserve existing journals. Location IDs are also multiplayer room IDs. Update the native Destinations.h, Waters.h, art, browser catalog and fixtures together when changing schemas. The original habitat illustrations and deployable palette variants are included. Render tests use the live engineering geometry.
