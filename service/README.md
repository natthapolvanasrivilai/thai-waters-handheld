# Field service
Record serial, as-built hardware revision, firmware release, fault, reproduction, remedy and retest result in the service register. For a reel complaint, read magnet status and direction in Bench. For a clock complaint, compare the online time with the retained time after a measured unpowered interval. For a failed update, retain firmware version and recovery logs and recover over USB.

Track affected serial ranges when changing cell supplier, antenna assembly, enclosure resin, charging firmware or haptic hardware. Publish signed update packages to the owner-controlled release service. Keep signing keys outside Git. Archive the matching build inputs, compatibility matrix and support end date.
