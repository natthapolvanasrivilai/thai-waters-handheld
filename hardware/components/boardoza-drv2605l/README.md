# A3 Boardoza DRV2605L R1.0

Order Boardoza B0601V10000076. Boardoza published the populated 18-solid STEP and PCB design under CC BY-SA 4.0. The files here are unmodified upstream assets. The installed assembly is a translated copy, split into original PCB and populated parts in electronics/haptic-r0009. Attribution and upstream license apply to the derived geometry. [Source revision](https://github.com/Boardoza/Boardoza_DRV2605L_Haptic_Driver_Breakout_Board/tree/a23e28dcaa4ffa82e68108e668a1f46f7c24a0a8) · [Order](https://www.digikey.com/en/products/detail/boardoza/B0601V10000076/30150547)

The 20 × 20 mm board retains its supplied header. J1 1–5 are VCC, IN/TRIG, SCL, SDA, GND. Feed filtered 3.3 V. Ground IN/TRIG locally. The onboard pull-ups are 2.2 kΩ. Verify the assembled bus before power-up. TP1 is OUT+, TP2 OUT−. The device uses I²C address 0x5A. Identify R1.0 and its populated header on receipt.
