# R0009 engineering assembly

R0009 is the current design for engineering review. It integrates the USB shroud and flexible mask, separate light guides, a fitted 8 Ω speaker, the folded reel and a removable rod. The paired electrical integration is R0003. R0008 / R0002 is the released inert-print baseline. First-article fit, electrical measurements and production approval are open.
